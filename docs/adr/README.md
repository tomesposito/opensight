# Decision records

When a decision in `SOLUTION_DESIGN.md` outgrows its section — long option analysis,
experiments, reversals — it gets a full ADR here, numbered sequentially:

```
docs/adr/0001-duckdb-query-engine.md
```

Each ADR follows: Context → Options → Decision → Consequences → Status.
`SOLUTION_DESIGN.md` keeps the summary and links here.
